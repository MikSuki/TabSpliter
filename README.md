# TabSplitter

<!-- Plugin description -->
## What's TabSplitter?

This is an IntelliJ extension that allows you to horizontally split the editor.

While there are already several extensions that offer this feature, I found some of them a bit inconvenient, so I made it.

## What Makes It Different

- Implements a tab switcher that only switches files within the current editor window.
- Allows directly splitting a file to the **left side**—most tools only initialize the splitter on the right.
- Lets you **jump directly** to a specific splitter, instead of moving step by step.


## Hotkeys

> Some hotkeys may conflict with your default IntelliJ keymap, so you might need to customize them.

| Action                                  | Shortcut           |
|-----------------------------------------|--------------------|
| Move file left                          | Alt + Left         |
| Move file right                         | Alt + Right        |
| Switch to next file                     | Ctrl + Tab         |
| Switch to previous file                 | Ctrl + Shift + Tab |
| Switch to next file(when switching)     | Ctrl + Down        |
| Switch to previous file(when switching) | Ctrl + Up          |
| Select Tab 1                            | Ctrl + 1           |
| Select Tab 2                            | Ctrl + 2           |
| Select Tab 3                            | Ctrl + 3           |
| Select Tab 4                            | Ctrl + 4           |
| Select Tab 5                            | Ctrl + 5           |
| Select Tab 6                            | Ctrl + 6           |
| Select Tab 7                            | Ctrl + 7           |
| Select Tab 8                            | Ctrl + 8           |
| Select Tab 9                            | Ctrl + 9           |
